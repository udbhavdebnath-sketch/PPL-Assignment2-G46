## Prompt 1 – Understanding the problem and Prolog representation

Before starting implementation, read the P1 section of the CS F301 Assignment 2 PDF.

I am implementing only Problem 1 using Prolog.

Explain the problem in simple English and help me understand:

1. The attributes and possible values involved in the puzzle.
2. How each friend and their assignments should be represented.
3. How to represent a complete assignment using Prolog terms.
4. How the individual clues can be represented as predicates.
5. How backtracking can be used to generate possible assignments.

Do not implement the complete solution yet. Focus on understanding the problem and deciding on a suitable representation.
