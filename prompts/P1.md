# P1 – AI Prompts and Usage

The following records describe the AI assistance used while working on Problem 1. Some entries are summaries of the actual interactions rather than verbatim transcripts.

## Prompt 1 – Understanding the problem

I have to solve only Problem 1 of the PPL assignment using Prolog. Help me understand the problem and how I should represent the different attributes and assignments in Prolog. Explain it in simple English.

**Purpose:** Understand the problem representation and plan the predicates.

## Prompt 2 – Generating possible assignments

Help me implement the base solution for P1 using permutations. Each department, programming language and project should be assigned exactly once. Keep the code simple and explain the logic.

**Purpose:** Create the base solution representation using Prolog.

## Prompt 3 – Implementing the clues

Help me implement the individual clue predicates and the solve predicate so that only assignments satisfying all the given clues are returned.

**Purpose:** Implement the constraints and generate valid solutions.

## Prompt 4 – Counting solutions

Help me implement a predicate called count_solutions/2 that takes a list of active clue numbers and returns the number of valid solutions satisfying those clues.

**Purpose:** Check the number of possible solutions for a selected set of clues.

## Prompt 5 – Adding the ninth clue

The first eight clues give three possible solutions. Help me introduce an additional clue that reduces the number of valid solutions to exactly one. Also explain how to test it.

**Purpose:** Implement and verify the additional clue.

## Prompt 6 – Testing the implementation

Help me create separate automated tests for P1 using SWI-Prolog. Include tests for the original clues, the additional clue, the solution count and the final assignment.

**Purpose:** Verify the implementation using PL-Unit.

## Prompt 7 – Debugging the tests

My Prolog tests are passing but showing choicepoint warnings. Help me understand these warnings and remove them without changing the expected results.

**Purpose:** Make the test suite deterministic and remove unnecessary warnings.

## Summary

AI assistance was used for understanding the problem, developing Prolog predicates, debugging the implementation and creating automated tests. The final implementation and test results were checked using SWI-Prolog.
